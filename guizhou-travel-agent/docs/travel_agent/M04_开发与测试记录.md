## 1 本轮实现

在 M3 已验收的桌面源码上，接入一条贵阳两人两天的最小行程。用户在本机页面填写日期、预算和游玩时段，明确确认贵阳北站返程，再点生成。后端用 M3 补齐检查，经现有单 Agent 的结构化 turn 调用本地行程 Skill，给出两天四站、五段路段和一段锁定返程安排。页面支持编辑未保存站点的到离时刻、重新校验、取消、确认保存和读取。保存复用 M3 的真实认证、SQLite 和幂等事务。此入口是本机验收页，M11 的正式网页聊天接入安排不变。

最小合约检查覆盖日期、到离时刻、站点与入口关系、预算口径、路线时间单位与证据引用、返程锁定和禁止将待查升级为可行。路线适配器沿用旧项目 OSM `route` 的 WGS84 点串和 `foot/car`、米/秒字段，去掉旧适配器只允许指定车站和景区的限制。预算沿用旧纯计算的「单位金额 × 数量」原则，使用新版费用行。未复用旧项目的执行器、数据文件或账号。样例坐标明确标注模拟，未把同名异地 POI 或景点几何中心当真实入口。

草稿可保存为**待核实**。当已知时段发生冲突，例如进站缓冲会挤占锁定返程，界面显示原因并拒绝保存该版本。没有已确认的下一站时仅展示端点示意，保持 `next_stop_id=null`，不画引导路线。已保存版本在本模块只读。已有不含时间轴的 M3 版本仍能读取。

## M4-08 真实地图实测

- **演示日**为 2026-12-05。选贵阳甲秀楼浮玉桥北端步行口（甲秀广场侧）到南端步行口（翠微园侧）。两端分别是 WGS84 26.5754098, 106.7156904 与 26.5747214, 106.7161334。比对了浮玉桥步行线两端的地图节点和政府公开资料。北段、南段步行线在地图上分别为 459593027 与 1058249913。 [贵阳市政府甲秀楼资料](https://english.guiyang.gov.cn/2019-04/17/c_355976.htm) · [北端地图节点](https://www.openstreetmap.org/node/7805809929) · [南端地图节点](https://www.openstreetmap.org/node/7805809930)
- **采集时间**为 2026-11-26 15:17:31 北京时间。复用现有的 osm-mcp 0.3.2，经本机 stdio 初始化及工具登记后，用公开 OSRM 的 foot profile 调用一次 route。该组件使用数值坐标，未把地名交给地理编码器。未安装依赖，未用 Key、重试或付费请求。
- **实测结果**为 89 米、71 秒。时间轴使用向上取整的 2 分钟做排程，同时保留原始米秒。Chrome 离线打开已经保存的响应，确认显示「OSM 实测 89 米 / 71 秒」，且实测路段只出现在第一站的 incoming_leg。其余路线未查询，时间轴其它站点为联调样例，费用总额保持待查。地图距离与估时取自采集日，12 月 5 日的开门、施工、通行和返程安排没有实测或预订。
