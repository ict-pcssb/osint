| 业务字段与安全检查 | 检查请求与结果的日期、地点、子类型、版本和已知锁定安排，检查币种、费用乘法、已知下界、未知金额、证据 ID、时间轴顺序和具体入口。网页使用文本节点，链接过滤协议与明显的本地地址 |

| 本模块业务边界 | 天气等供应商和无绑定 Skill 走结构化待核实。行程卡是按天时间轴的样例，局改卡是差异预览。可编辑行程业务、真实后台校验、保存、账号和数据库未在 M02 实施 |
