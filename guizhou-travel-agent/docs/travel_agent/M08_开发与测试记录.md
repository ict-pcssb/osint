# M08 打车 住宿和餐饮候选开发与测试记录

2026 年 11 月 26 日，北京时间。**10 项固定测试和三条真实供应商业务链均 PASS，本机 Chrome 10 个断言通过，等用户验收。** 高德控制台实际账单对照单列未验。本轮只实施 M8。

## 开发结果与验收对照

复用 M2 结构化问答、M3 会话与账户校验、M5 原文证据和 M6 金额口径。高德、RollingGo 和地图查询仍由同一个主 Agent 调用。候选选择只触发行前报价，保存权限留在原有行程机制里。参考项目为只读，本轮沿用现有 Python 和浏览器环境。

| 原文用例 | 层级 | 实际结果 |
| --- | --- | --- |
| M8-01 | 集成、浏览器 | PASS。首轮出现两个固定上车点，用户选择第二项以后才报经济型 ¥80–110 元整车价。测试按字节比较同轮原始上下文并核对所选起点。真实高德另返回了四个选项，由用户实际选择东广场后得出报价。 |
| M8-02 | 隔离和 SQLite 集成 | PASS。跨账号、同账号跨会话、伪造选项、过期上下文分别被拒。原工具调用仍为 1 次，未回显供应商上下文，业务表零新增。 |
| M8-03 | 契约和固定回放 | PASS。经济 ¥80–110 与商务 ¥150–200 分车型，选经济只显示经济。异常、新场景和订单回包分支均只交付待查。 |
| M8-04 | 费用契约 | PASS。每晚 ¥260，2 晚但入住总价缺失时仍为 `null`。无价候选不展示数字，无自动预订。 |
| M8-05 | 契约和集成 | PASS。酒店 ID 取自本次搜索，核对两位成人一间房两晚、退房日期、CNY 和 USD 分开、按需确认库存及缺少退改字段。补测家庭入住时，儿童人数和年龄按实际房型接口字段传入，搜索口径的参考价不用于儿童或多房的完整比较。 |
| M8-06 | 固定回放 | PASS。三篇同来源推广归并为一条，独立到访数为 0。另验证具备署名、明确日期的近期到访才单列。旧餐馆地图标签保留原采集时间，仍无法确认当晚营业。 |
| M8-07 | 规则和 SQLite 集成 | PASS。较便宜的酒店到次日首站多 70 分钟，卡片明示路段与价格取舍，保留用户决定。查询前后原酒店、返程锁定项和版本一致。 |
| M8-08 | 失败恢复 | PASS。空、401、429、额度用尽、畸形数据分开标记。房型查询部分失败仍保留有效候选，认证失败和限额问题停止后续同供应商详情查询。 |
| M8-09 | 并发、缓存和 SQLite 集成 | PASS。两次并发选择只新增一次报价调用。价格超过 5 分钟标过期，原采集时间保持，用户可以发起新查询。无行程写入。 |
| M8-10 | 浏览器、定点模拟、真实只读 | PASS。固定测试验证多文本块回包和原文匹配；Chrome 走本机认证 HTTP 和 SQLite，验证选点、报价、酒店缺总价、失败后继续查询和餐饮首备选。真实高德、RollingGo、餐馆地图及公开原文均通过。 |

候选请求只在有对应数据时展示真实价格和时段。酒店总价只取供应商明确的总价字段，住宿与餐饮路线在缺精确坐标、时段或资料时保留待查。出站接驳已知时可用 OSM 驾车估算，公开餐饮原文按精确实体匹配并保留采集时间。高德上下文只在后端短期持有，选点请求只提交两个不透明 ID。

## 实际执行命令

开发前先写完十项固定输入与断言，首次执行因模块尚未创建而失败。实现后运行同一入口通过，最后在接完真实链与浏览器后再跑一次。

```powershell
$env:PYTHONPATH=(Resolve-Path tests/travel_agent).Path
.\.venv-flight\Scripts\python.exe -B -m unittest discover -s tests/travel_agent/m08 -p 'test_*.py' -v
.\.venv-flight\Scripts\python.exe -B scripts/travel_agent/run_module.py M08 --report docs/travel_agent/evidence/m08/fixed/report.json
foreach ($module in 'M01','M02','M03','M04','M05','M06','M07') {
  .\.venv-flight\Scripts\python.exe -B scripts/travel_agent/run_module.py $module --report "docs/travel_agent/evidence/m08/$module-regression/report.json"
}
.\.venv-flight\Scripts\python.exe -B scripts/travel_agent/demo_m08.py --browser 'C:/Program Files/Google/Chrome/Application/chrome.exe' --output docs/travel_agent/evidence/m08/browser
.\.venv-flight\Scripts\python.exe -B scripts/travel_agent/preview_m02.py --browser 'C:/Program Files/Google/Chrome/Application/chrome.exe' --output docs/travel_agent/evidence/m08/m02-browser/preview.html
.\.venv-flight\Scripts\python.exe -B scripts/travel_agent/preview_m07.py --browser 'C:/Program Files/Google/Chrome/Application/chrome.exe' --output docs/travel_agent/evidence/m08/m07-browser
.\.venv-flight\Scripts\python.exe -I -B -m pip check
```

真实供应商的成功、失败命令和具体数据单列。高德与酒店首轮发生本地 MCP 流拆包错误，酒店详情需按当前接口修正旧筛选参数。餐饮先遇到 Overpass 超时，再通过 OSM 官方地图小范围查询和可匹配的公开原文完成闭环。[M08 真实只读实测记录](M08_真实只读实测记录.md)

## 未测与回滚

控制台实际账单明细未提供，平台计数与金额对照记为 **BLOCKED**。本地已记录高德 2 次行前业务调用及协议次数。真实模型和目标部署环境网页端到端 **SKIPPED**，原因是本轮验收使用固定意图、真实只读供应商和本机页面。现场营业、实际库存与缺失总价保持待核实。

关闭 `TRAVEL_M08_NETWORK` 后重启可回到 M7。单个供应商可撤销 `TRAVEL_M08_AMAP`、`TRAVEL_M08_HOTEL` 或 `TRAVEL_M08_FOOD`。短期上下文随进程清除，已有行程及锁定安排继续读取。恢复 M7 源码后复跑 M2、M3 和 M7，并验证 M8 缺价、隔离及幂等回放。无需删除或迁移业务数据。

**验收结论**。M8 固定关卡和真实业务主链均通过，等用户验收确认。本轮未实施 M9。
