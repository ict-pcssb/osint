## 手动试用与回滚

在项目根目录运行 `.\.venv-flight\Scripts\python.exe -B scripts/travel_agent/demo_m10.py`，打开终端打印的地址。先看到已保存行程，随后出现固定公告的差异。点「保留原行程」，再点「重新打开行程」，可以检查拒绝记录、站点和 r8 是否保留。想试 M9 授权链，需在拒绝前点「查看替换预览」，再按预览确认。退出演示后临时数据库由脚本清理。

设置 `TRAVEL_M10_AUTO_OPEN=0` 并重启即可关闭打开时的自动核查，保留只读行程和手动复查。服务退出时停止领取新的供应商调用并收尾在途任务。撤回 M10 可恢复 M9 的入口与源码，保留复查历史记录和原行程版本。已确认的修改仍走 M9 的版本恢复机制。
