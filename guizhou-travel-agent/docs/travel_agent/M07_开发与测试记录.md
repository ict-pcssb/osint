# M07 天气查询与跨城接驳测试记录

2026 年 11 月 26 日，北京时间。**M7 达到验收标准，等用户确认。** 固定套件 10 项 PASS，Open-Meteo、12306、主备航班和补测的 OSM 接驳均通过真实只读测试。共执行 6 次工具调用，业务写入为 0。本轮止于 M7。

## 改了什么

- 在现有单 Agent 的结构化问答入口接入天气、站到景区入口的接驳、铁路和航班候选。明确比较铁路和航班时，复用已有组合卡分别展示。查到一种方式时保留该卡，另一种可以显示待查。M7 没有新增长期存储或行程写入入口。
- 青岩天气按北京时间查询指定日，标出花溪区覆盖、温度和概率单位、采集时间及一条建议。明确需要逐时时才查询逐时。数据失效时保留地点与日期，仍然可以直接问天气，不必建行程。
- 用已登记 ID 区分铜仁站、铜仁南站、梵净山东门、西门及停车场。东门、西门使用参考项目的既有映射点，停车场未填入未经核实的坐标。OSM 使用 WGS84 纬度在前，高德转换复用参考项目的坐标公式，未启用高德联网。
- 接驳保留地图估算和由证据或明确输入支持的时间信息。复用 M5 核验结构检查上车点、方向、日期和站点原文，复用 M6 检查缓冲、跨午夜和预约。末班缺证据时保留待查。车票、返程和预约由原有状态机制管理。
- 12306 先精确查站码，再查指定站点和日期的车次。航班继续用现有 `flights`，另接既有 `fli` 备用配置。两者按同一个 Google Flights 来源归组，保留车票席别与余票、航段和日期。查询结果仅为交通候选，缺人数口径、税费、接驳耗时或费用时保留待查。门到门计算接受已知的进站、末段和缓冲数据，当前演示未配置真实接驳费用或班表。

## 回滚

将服务进程的 `TRAVEL_M07_NETWORK` 设为 0 或撤销该变量，重启后即回到只读待查与 M6 时间轴。也可分别撤销 `TRAVEL_M07_WEATHER_ENTRY`、`TRAVEL_M07_RAIL_ENTRY`、`TRAVEL_M07_OSM_ENTRY`、`TRAVEL_M07_FLIGHTS` 或 `TRAVEL_M07_FLI` 关掉相应供应商。若需回退代码，从 M6 验收快照恢复上述改动文件，复跑受影响的 M02、M03、M05、M06 和 M4 浏览器回归。此模块没有数据库迁移，回退无需删除用户数据。

**验收结论**。固定测试、本地 Chrome、回归和真实只读冒烟均已通过，等待用户验收。实际公交末班、未确认的航班人数口径、税费及门到门总价仍按待查交付。
