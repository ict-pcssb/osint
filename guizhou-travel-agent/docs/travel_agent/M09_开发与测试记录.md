## 回滚

设置 `TRAVEL_M09_COMMIT=disabled` 并重启当前应用进程，可以停用新提交并清除未确认提案，已存行程仍可读。模块测试已实际验证停用后确认被拒、业务表零新增。需要撤回功能时，可恢复验收前的 M8 源码和界面。已提交的历史版本保留，业务上需要撤销时基于当前版本准备可审核的反向修改并取得用户确认。

**结论：达到 M9 验收标准，等待验收确认。M10 尚未开始。**
